# Examples

Each script makes one or two requests and prints the answer. Install the library first, then set your API key:

```bash
npm install github:DataPorium/dataporium-js
export DATAPORIUM_API_KEY="YOUR_API_KEY"
```

| Script | What it does |
|---|---|
| `quickstart.mjs` | A company profile, for example `node quickstart.mjs AAPL` |
| `stock-prices.mjs` | The last ten daily bars of a stock, ETF, index or cryptocurrency |
| `yield-curve.mjs` | Today's US Treasury yield curve next to one month and one year ago |
| `housing-search.mjs` | Homes for sale in a ZIP code with a recent price cut |

*Data is for information only and is not investment advice.*
